# Portfolio

Welcome to the source code of my personal portfolio website!

This is a modern, responsive, and interactive portfolio built using HTML, CSS, and Vanilla JavaScript. It showcases my journey, education, skills, projects, and certificates as a Computer Science undergraduate.

## Features
- **Glassmorphism UI**: A sleek, modern aesthetic using translucent glass panels.
- **Dynamic Content Loading**: Projects and Certificates are injected via `data.js` and parsed dynamically.
- **Interactive Animations**: Custom cursors, background particle canvas, and scroll progress bars.
- **AI Chat Widget**: A built-in chat UI placeholder for future Gemini/RAG integration.

## How to Run Locally
1. Clone this repository.
2. Open `index.html` in your favorite web browser.
3. No build steps or server required! (For the best experience, you can use a local server like Live Server).

## Customization
- To update your projects or certificates, edit the JSON structures in `data.js`.
- If you use the python updater script, run `python update_data.py`.
